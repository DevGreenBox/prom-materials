# Пром-Материалы — рабочие правила

Интернет-магазин промышленной автоматики и электрооборудования.
ТЗ заказчика — в [CLAUDE.md](CLAUDE.md), он главнее этого файла.
Дизайн-система — в [docs/design-system.md](docs/design-system.md), состояние — в [docs/state.md](docs/state.md).

Стек: Next.js 16 (App Router, Turbopack), React 19, TypeScript, Tailwind CSS 4, pnpm.

## Что нельзя выдумывать

- **Каталог.** Собран из действующих объявлений заказчика на Авито:
  `pnpm items` (выгрузка) → `pnpm catalog` (разбор). Руками
  `content/catalog/*.json` не правим — правим правила разбора в скрипте.
- **Названия и цены.** Ровно те, что в объявлении. Названия не переписываем
  (`pnpm check` сверяет их с выгрузкой), цены не округляем и не пишем «от».
- **Чего в объявлениях нет — того нет на сайте.** Ни массы, ни остатка
  в штуках, ни срока поставки: API отдаёт только название, цену, категорию,
  адрес и ссылку.
- **Фотографии.** В API их нет. Единственный источник — страницы профиля,
  сохранённые из браузера в `inbox/*.html`: `pnpm images` достаёт из них
  снимки в `public/images/products/`. Скрапить Авито и обходить защиту
  не будем — страницы сохраняет человек.
- **Реквизиты и почта.** Помечены `TODO(client)` в `lib/site.ts`. Телефон
  и адрес склада — настоящие, из профиля и объявлений.
- **Тарифы доставки и оптовые скидки.** Условные, отмечены комментарием.

Флаги: `DEMO_CATALOG` и `FORMS_ARE_MOCKED` в `lib/site.ts`. Перед запуском —
снять их, убрать `robots: { index: false }` из `app/layout.tsx` и disallow
из `app/robots.ts`.

## Где что лежит

- `app/` — маршруты; `components/` — компоненты; `lib/` — данные, утилиты, стор
- `content/catalog/` — разделы и позиции (данные, не разметка)
- `scripts/` — выгрузка из Avito API, сборка каталога, фото, проверка контента
- `docs/` — бриф, дизайн-система, состояние
- `assets/` — исходники, наружу не отдаются
- `inbox/` — сохранённые страницы Авито для `pnpm images` (в git не идут)

## Правила

- Токены дизайн-системы — в `app/globals.css`. Свои цвета и размеры не вводим:
  палитра одна, акцент один (`--color-accent`), красного на сайте нет.
- Данные (позиции, характеристики, тарифы) — в `content/` и `lib/`, не в разметке.
- Корзина, избранное и заказы живут в `localStorage` через `lib/store.ts`
  (`useSyncExternalStore`). Сервера у проекта нет.
- Анимации: 120–200 мс, только цвет, прозрачность и сдвиг. Всё уважает
  `prefers-reduced-motion`. Контент никогда не зависит от того, сработал ли скрипт.
- Иконки берутся из `components/icons.tsx`. Стрелки, крестики и плюсы символами
  (`→`, `×`, `+`) и эмодзи в разметке запрещены — разнобой толщин выдаёт шаблон.
- Один способ выделения на элемент: рамка **или** заливка **или** тень.
- Текст не объясняет себя: утверждение один раз, без «поэтому», без пересказа
  соседним предложением и без противопоставлений «X, а не Y». Прилагательные —
  измеримые; «надёжный», «удобный», «широкий ассортимент» запрещены и ловятся
  в `pnpm check`.
- Отзывы живут в `content/reviews.json` и обновляются `pnpm reviews`
  (Avito API, ключи в `.env.local`). Руками их не пишем и не выдумываем.
- Перед сдачей — `pnpm check`: проверяет каталог, подгруппы и популярные запросы
  (ссылка не должна вести в пустую выдачу).
- Мобильная вёрстка первична; нажимаемое — от 44 px; поля ввода 16 px.
- Проверка изменения — открыть страницу в браузере (playwright MCP) на 390 и 1440,
  а не только собрать проект.
- После значимого шага — обновить `docs/state.md`.
