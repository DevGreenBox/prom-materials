# Пром-Материалы

Интернет-магазин промышленной автоматики и электрооборудования:
каталог с подгруппами и фасетным фильтром, поиск по артикулу и номиналу,
корзина, оформление заказа, личный кабинет, избранное, расходная накладная,
расчёт доставки.

Next.js 16 (App Router, Turbopack) + React 19 + TypeScript + Tailwind CSS 4.

> **Каталог настоящий.** 1882 позиции, названия, цены, наличие и адрес склада
> собраны из действующих объявлений заказчика на Авито через официальное API
> (`pnpm items` → `pnpm catalog`). Фотографии (1410 из 1882) достаются
> из сохранённых страниц профиля в `inbox/*.html` (`pnpm images`) — в API
> их нет; всего 6690 снимков, до пяти на позицию. У позиций без фото стоит
> шильдик с номиналом. Отзывы — 635, `pnpm reviews`. Доставку считает СДЭК
> (`app/api/cdek`), ключи интеграции — в `.env.local`.
>
> Заглушки, которые остались: почта, реквизиты, ключи СДЭК и пороги
> оптовой скидки (`TODO(client)` в `lib/site.ts`), формы ничего не отправляют,
> заказы хранятся в браузере. Сайт закрыт от индексации.

## Страницы

| Маршрут | Что это |
| --- | --- |
| `/` | Витрина: поиск, разделы, лента со склада, опт, производители, доставка, отзывы, вопросы |
| `/catalog` | Полный список позиций с фасетным фильтром |
| `/catalog/[раздел]` | Раздел: подгруппы и позиции |
| `/catalog/[раздел]/[подгруппа]` | Подгруппа с фасетным фильтром |
| `/product/[slug]` | Позиция: галерея, цена, характеристики, покупка |
| `/search` | Поиск по названию, коду позиции, производителю и номиналу |
| `/cart`, `/checkout` | Корзина с расчётом доставки СДЭК и оформление заказа |
| `/favorites`, `/compare` | Избранное и сравнение до четырёх позиций |
| `/account` | Кабинет: заказы, списки закупки, реквизиты |
| `/account/orders/[id]` | Заказ и расходная накладная (печать или PDF) |
| `/corporate`, `/delivery`, `/payment` | Оптом и юрлицам, доставка, оплата |
| `/about`, `/contacts` | О компании, контакты и заявка |
| `/reviews` | Отзывы покупателей — 635 с оценками |
| `/privacy`, `/offer` | Обработка данных, условия продажи |

## Запуск

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build
pnpm lint
pnpm check    # проверка каталога, подгрупп и популярных запросов
pnpm items    # выгрузить объявления из Avito API (ключи в .env.local)
pnpm catalog  # собрать каталог из выгрузки: разделы, бренды, номиналы
pnpm images   # достать фотографии из сохранённых страниц в inbox/*.html
pnpm reviews  # обновить отзывы и рейтинг из Avito API
```
